## Projects

**[SOC Triage Journal](https://github.com/cyberlandji/soc-triage-journal)** — Blind L1 alert triage in Elastic. The answer key is encrypted and committed before each run, so verdicts can't be corrected afterwards. Reports and mistakes are published as they are.

**[Prism Box](https://github.com/cyberlandji/prism-box)** — Cloud-hosted Elastic SIEM + EDR lab. An 11-step Lumma Stealer chain emulated with Atomic Red Team and traced through endpoint and SIEM evidence.

**[Operation PCAP Autopsy](https://github.com/cyberlandji/operation-pcap-autopsy)** — Four real malware infections (STRRAT, Lumma Stealer, GhostWeaver, NetSupport RAT) reconstructed from network captures and mapped to MITRE ATT&CK.

**[The Forge](https://github.com/cyberlandji/the-forge)** — 38 Suricata rules replayed on every push against malicious and benign traffic. Pipeline built with AI assistance; rules and test cases are my own.
[![CI](https://github.com/cyberlandji/the-forge/actions/workflows/suricata.yml/badge.svg)](https://github.com/cyberlandji/the-forge/actions/workflows/suricata.yml)

**[Operation Iron Watch](https://github.com/cyberlandji/operation-iron-watch-03)** — SOC lab series: Snort IDS, Graylog log management, DMZ hardening with a full log pipeline.

**[SigmaHQ PR #6110](https://github.com/SigmaHQ/sigma/pull/6110)** — Network-layer detection for NetSupport Manager RAT C2, derived from PCAP Autopsy. Under maintainer review.
